# Vyntex Phone App Store Release

This project now supports shipping the existing phone experience as native Android/iOS apps with Capacitor.

## Scope

- Included: `phone.html` + `src/phone-app/*`
- Included: waiter / staff POS on phone via `#/pos` (license key + PIN login)
- Excluded: desktop Electron flow

## One-time setup

1. Install dependencies:
   - `npm install`
2. Sync native projects:
   - `npm run cap:sync`

## Supabase Auth Redirects

Add this redirect URL in Supabase Authentication settings:

- `com.vyntex.phone://auth/callback`

Notes:

- Android deep link handler is configured in `android/app/src/main/AndroidManifest.xml`.
- iOS URL scheme is configured in `ios/App/App/Info.plist`.
- The app listens for incoming deep links and forwards auth URLs to `#/auth/callback`.

## Build commands

- Build phone web bundle only:
  - `npm run build:phone:web`
- Sync web bundle into native projects:
  - `npm run cap:sync`
- Open Android Studio:
  - `npm run cap:open:android`
- Open Xcode:
  - `npm run cap:open:ios`

## Release artifacts

- Android AAB (Play Store):
  - `npm run dist:android:aab`
  - Output is generated by Gradle under `android/app/build/outputs/bundle/release/`.
- iOS Archive (App Store):
  - `npm run dist:ios:archive`
  - Then archive in Xcode and upload via Organizer / App Store Connect.

## Validation checklist

1. Launch app on Android/iOS simulator/device.
2. Confirm app opens as native shell (not browser tab).
3. Login flow works and returns to app after auth callback.
4. `Mobile access` gate blocks disabled licenses.
5. Verify all phone routes work:
   - `/app`, `/app/venue`, `/app/orders`, `/app/stock`, `/app/staff`, `/app/profile*`
   - `/pos` (license activation + staff PIN login)
