Kodi React për versionin e telefonit (UI / hook-e / rrugë vetëm për mobile)
gjendet në: src/phone-app/

Hyrja e dytë Vite (pa site publik): phone.html
  • Dev: npm run dev  →  http://localhost:5173/phone.html  (ose /phone)
  • Në telefon (i njëjti Wi-Fi): http://IP_E_PC:5173/phone.html
  • Prod: https://www.vyntexpos.net/phone.html  (ose /phone)
  • Build: dist/phone.html (bashkë me dist/index.html)

Rruga (HashRouter): phone.html#/ → login → #/app (dashboard mobil), #/pos, #/admin.
Shembull: http://localhost:5173/phone.html#/login

Import në projekt: @/phone-app/...  (shembull: @/phone-app/components/Foo)

Kur shtohet Capacitor, projektet native (android/, ios/) zakonisht vendosen
në këtë dosje ose në rrënjë — vendos sipas dokumentimit të Capacitor.

Nëse shfaqet "Nuk u gjet biznes": Supabase → SQL Editor → ekzekuto të gjithë skriptin:
  supabase/ensure_vyntex_phone_pos_access.sql
  (kopje e njëjtë: supabase/ensure_vyntex_my_restaurant_rpc.sql)
Përfshin: RPC vyntex_my_restaurant + politika RLS për restaurants (lexim/përditësim sipas
email-it të JWT dhe metadata). Pa RLS të përshtatshme, kërkesat .from("restaurants") dështojnë
edhe kur RPC ekziston. Pas ndryshimit të skedarit, run përsëri në Supabase.
